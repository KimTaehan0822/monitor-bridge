# Monitor Bridge

[한국어](README.md) | [English](README.en.md) | **日本語**

ゲーミングPCのキーボードとマウス1組で、配信PCまで操作できる Windows 用プログラムです。Input Director に似ていますが、**モニターごとに自由に配置**できます。

例: 机の上が `配信1 | ゲーム | 配信2` の順なら、カーソルもその順に移ります。1台のPCにモニターを3台つないだように使えます。

- マウス・キーボードの共有（ゲーミングPC → 配信PC）
- クリップボード共有（双方向）: テキスト、画像、ファイル
- ロックキー: カーソルを今いるPCから出さない（ゲーム中に）
- クイック切り替えキー: キー1つで相手のPCへ移動。着いた場所に波紋が広がり、カーソルを見つけやすい
- 接続中、カーソルがゲーミングPCにある間は配信PCのカーソルを隠す（配信画面に矢印が残らない）

プログラムの画面は韓国語です。以下では韓国語の表示をそのまま載せ、意味を添えています。

## 必要なもの

- Windows 10 以降の 64 ビット PC 2台（ゲーミングPC 1台、配信PC 1台）
- 2台が同じルーター（LAN）につながっていること
- 最初の設定のときだけ配信PCに挿すキーボードとマウス

.NET を別途インストールする必要はありません（exe に入っています）。

## クイックスタート

### 1. 配信PCにキーボードとマウスを一時的に挿す

最初の設定は配信PCで直接行います。このプログラムが起動して接続するまでは、ゲーミングPCから配信PCを操作できません。設定が済んだら外してかまいません。

### 2. Input Director などのプログラムを終了する

Input Director、Mouse Without Borders、Barrier などと**同時に動かすと入力が混乱します。** 両方のPCで終了するか削除してください。

### 3. 両方のPCで `MonitorBridge.exe` を起動する

exe を好きなフォルダーに置いて起動します。初回は設定ウィンドウが開きます。

**配信PCで:**
1. **이 PC는**（このPCは）で **송출컴**（配信PC）を選びます。
2. **비밀번호**（パスワード）を決めて入力します。ゲーミングPCにも同じものを入れます。
3. ウィンドウ下に出る **이 PC의 IP**（このPCのIP）を控えます（例: `192.168.0.10`）。
4. **윈도우 로그인 시 관리자 권한으로 자동 실행**（Windows サインイン時に管理者として自動起動）をオンにして保存します。管理者の確認が出たら **はい** を押します。
5. ファイアウォールの **アクセスを許可** が出たら **プライベート ネットワーク** にチェックして許可します。

**ゲーミングPCで:**
1. **이 PC는** で **게임컴**（ゲーミングPC）を選びます。
2. **송출컴 IP**（配信PCのIP）に控えたIPを入れます。
3. **비밀번호** に配信PCと同じパスワードを入れます。
4. 保存すると配信PCに接続します。タスクバー右のアイコンが**青緑色**になれば接続済みです。

### 4. モニターを机の上と同じ配置にする

ゲーミングPCのトレイアイコンをダブルクリックすると設定が開きます。下の **모니터 배치**（モニター配置）で、モニターの四角を実際の机の順にドラッグして保存します。

- 青緑はゲーミングPCのモニター、紺は配信PCのモニターです。
- 近づけると隣のモニターにぴったり付きます。
- 赤い枠はモニターが重なっている印です。横にずらしてください。

### 5. 確認したら配信PCのキーボードとマウスを外す

ゲーミングPCのマウスで配信PCの画面まで行き来できたら、配信PCのキーボードとマウスは外してかまいません。

## ショートカット

| 機能 | 既定のキー | 説明 |
| --- | --- | --- |
| ロック（가두기） | `Scroll Lock` | カーソルを今のPCに閉じ込めます。もう一度押すと解除。ロック中はトレイアイコンがオレンジで、クイック切り替えも止まります |
| クイック切り替え（빠른 전환） | ``Ctrl + Alt + ` `` | 相手のPCへすぐ移ります。そのPCで最後にいた場所に移り、そこに波紋が少し広がります。配信PCの波紋は配信画面にも一瞬映ります |

- **キーの変更**: 設定で入力欄をクリックすると色が変わり「새 키를 누르세요」（新しいキーを押してください）と出ます。その間は今のショートカットが動かないので、使いたいキーを押すだけです（Esc: 取り消し）。
- **使わない**: 欄を空にすると（**[지우기]**（消去）ボタン、または欄を押して Backspace）、その機能はオフになり、キーも横取りしません。
- ゲーミングPCでロックすると、このプログラムはキーボードとマウスの監視を完全に止めるので、ゲームに影響しません。
- 配信PCでロックすると、カーソルは配信PCのモニターから出ません。このときは**配信PCの Windows のディスプレイ配置**に従って動くので、机の上で配信モニターの間にゲーミングモニターがあっても配信モニター同士は行き来できます。
- 未接続のときは、ショートカットを含むすべてのキーとマウスに触れません。同じキーを使う他のプログラムもそのまま動きます。

## ファイルを移す

1. 送る側のPCでファイルやフォルダーをコピー（Ctrl+C）します。**コピーだけでは何も送られません。** 相手のPCに「こういうファイルをコピーした」という一覧を知らせるだけです。
2. 受け取る側のPCのエクスプローラーで、入れたいフォルダー（またはデスクトップ）の空いている所を**右クリック**します。
   - Windows 11 では **その他のオプションを確認** を押すか、最初から **Shift+右クリック** します。
3. **Monitor Bridge: 상대 PC에서 복사한 파일 여기에 붙여넣기**（相手のPCでコピーしたファイルをここに貼り付け）を押します。
4. カーソルの横に「이 폴더로 가져올까요?」（このフォルダーに取り込みますか?）が出たら **[가져오기]**（取り込む）を押します。そこから転送が始まります。
5. 始まると通知が出ます。**トレイアイコンか通知を押すと**進行ウィンドウが開きます（進行率、残り時間、取り消しボタン）。配信画面に映らないよう、自動では開きません。
6. 終わると「다 받았어요」（受け取りました）の通知が出て、押すとそのフォルダーが開きます。

- 普段の Ctrl+V の貼り付けには触れません。
- 同じ名前があれば上書きせず `名前 (2)` のように保存します。
- **転送の取り消し**: 進行ウィンドウの **[전송 취소]** か、トレイメニューの **파일 전송 취소** を押します。どちらのPCで押しても両方が止まります。途中まで受け取ったファイルは自動で削除し、**送る側の元のファイルは決して削除・変更しません。**
- **コピー上限**: 既定 500MB、最大 100,000MB。**2台の上限のうち小さいほうまで**送れます。上限が違うと設定に赤い警告が出て、トレイメニューに両方の上限が表示されます。
- **転送速度**: 既定では **30MB/s** までで送ります。ファイルが LAN ケーブルを使い切ると配信PCの配信アップロードが押し出され、配信が途切れることがあるためです。設定の **파일 전송 속도**（ファイル転送速度）で変えられ（最大 1,000MB/s）、**0 にすると制限なし**になります。**2台のうち小さいほうの値**で送り（0 は制限なしなので一番大きい値として扱います）、転送中に変えて保存してもすぐに反映されます。

### 速度の目安

<details><summary>開く</summary>

- 1MB/s はインターネットの速度でいうと 8Mbps です。
- 1ギガ（1000Mbps）環境: 最大 約 110MB/s。ルーター、LAN ケーブル、両方のPCの LAN カードがすべて1ギガに対応している必要があります。
- 100メガ（100Mbps）環境: 最大 約 11MB/s。3つのうち1つでも100メガなら全体が100メガで動きます。
- Wi-Fi は速度が安定しません。
- 配信のアップロード: FHD ビットレート 8000kbps で1時間に約 4GB（余裕をみた値）、速度にすると約 1.1MB/s です。ケーブルに余裕が残っていないと配信が途切れます。

| 状況 | おすすめの値 |
| --- | --- |
| 1ギガ（1000Mbps）対応のネットワーク環境で配信中（ルーター、LAN ケーブル、両方のPCの LAN カードがすべて1ギガ対応） | 30MB/s（既定値） |
| 100メガ環境（どれか1つでも100メガ）、Wi-Fi、よくわからないとき | 5〜10MB/s |
| 配信していないとき | 0（制限なし） |

</details>

## 設定

| 項目 | 既定値 | 意味 |
| --- | --- | --- |
| 이 PC는（このPCは） | | 게임컴（ゲーミングPC、キーボードとマウスがある側）か 송출컴（配信PC） |
| 송출컴 IP（配信PCのIP） | | ゲーミングPCのみ。配信PCの設定に出るIP |
| 비밀번호（パスワード） | | 両方のPCで同じに。接続の暗号化に使います |
| ロックキー / クイック切り替えキー | `Scroll Lock` / ``Ctrl+Alt+` `` | ゲーミングPCのみ。空にするとその機能はオフ |
| ファイルコピー上限 | 500MB | 最大 100,000MB。2台のうち小さいほうが使われます |
| 파일 전송 속도（ファイル転送速度） | 30MB/s | 最大 1,000。0 = 制限なし。2台のうち小さいほうが使われます。**속도 기준 보기**（速度の目安を表示）で目安が開きます |
| 自動起動 | | Windows サインイン時に起動。配信PCは管理者として |
| 모니터 배치（モニター配置） | | ゲーミングPCのみ。実際の机と同じ順に |

接続には TCP ポート `24850` を使います。

## トレイアイコン

| 色 / メニュー | 意味 |
| --- | --- |
| 青緑 | 接続中 |
| 灰色 | 未接続 |
| オレンジ | ロック中 |
| メニュー先頭の `버전:` の行 | このPCの Monitor Bridge のバージョン |
| 上限の行 | 2台のファイルコピー上限 |
| 速度の行 | このPCの転送速度。2台で違うときは両方の値と実際に使う値 |
| 파일 전송 보기 / 파일 전송 취소 | 進行ウィンドウを開く / 転送を止める |

## よくあるトラブル

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 接続できない（アイコンが灰色） | 配信PCで起動していない、ファイアウォール、IP変更 | 配信PCで起動を確認 →「Windows Defender ファイアウォール → アプリを許可」で MonitorBridge を許可（または TCP 24850 を開く）→ 配信PCのIPを再確認（ルーターで固定すると便利） |
| 「비밀번호가 달라서 연결하지 못했어요」（パスワード不一致） | パスワードが違う | 両方に同じパスワードを入れ直す |
| 「두 PC의 Monitor Bridge 버전이 달라요」（バージョン違い） | 片方だけ更新した | キーボードとマウスはそのまま使えます。両方を同じバージョンに |
| 配信PCのサインイン画面を操作できない | プログラムはサインイン後に起動する | 配信PCの自動サインインをオンにするか、サインイン時だけキーボードを挿す |
| OBS など一部のプログラムがクリックできない | そのプログラムが管理者として動いている | 配信PCの設定で **관리자 권한으로 자동 실행** をオンにして再起動 |
| 右クリックの項目がない | Windows 11 の新しいメニュー、または一度も起動していない | **その他のオプションを確認** か Shift+右クリック、Monitor Bridge を一度起動 |
| 「Monitor Bridge가 실행 중이 아니에요」（起動していない） | そのPCで終了している | そのPCで先に起動 |
| ファイルコピーができない | 上限超え、空き容量不足 | 2台の上限を確認。受信中は対象フォルダー内の隠しフォルダー（`.MonitorBridge-받는중`）に先に書くので、その分の空きが必要 |
| 受け取ったファイルをフォルダーに移せない | ウイルス対策などがファイルを掴んでいる | ファイルは削除せず、通知に出た隠しフォルダーにそのまま残します |
| 配信PCのカーソルが見えない | 接続中なら正常 | ゲーミングPCのカーソルが移ってくると見えます。異常終了の後なら Monitor Bridge をもう一度起動 |
| Ctrl+Alt+Del の後でキーが押されたまま | その画面ではキーを離した信号が見えない | Ctrl と Alt を一度ずつ押して離す |

問題があれば `%AppData%\MonitorBridge\log.txt` を確認してください。設定は同じフォルダーの `config.json` に保存されます。

## 対応していないこと

- UAC（管理者の確認）画面、Ctrl+Alt+Del 画面、サインイン画面の操作
- 配信PCに移った状態でのゲーム（ゲームはゲーミングPCで、ロックキーをオンに）
- 3台以上のPC
- 同じルーター（LAN）の外からの接続

## 新しいバージョンへの更新

1. 両方のPCでトレイから Monitor Bridge を終了します。
2. 両方のPCの `MonitorBridge.exe` を新しいファイルで上書きします。元の場所に上書きすると、ファイアウォールの許可と自動起動がそのまま残ります。
3. 配信PC、ゲーミングPCの順にもう一度起動します。

バージョンが違ってもキーボードとマウスの接続は切れませんが、新機能の一部が動かないことがあるので、両方を同じバージョンにしてください。
