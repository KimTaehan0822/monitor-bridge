# 파일 전송 상태 표시와 한도 맞추기 (짧은 설계)

## 왜
- 큰 파일(70GB 녹화본 등)을 보낼 때, 지금은 사람이 제대로 전송되고 있는지 알 방법이 없다.
- 두 PC의 파일 복사 한도가 다르면 받는 쪽이 아무 말 없이 받지 않는다. 사용자는 무엇이 문제인지 알 수 없다.
- 설정에서 한도만 바꿔 저장해도 연결이 끊겼다가 다시 붙는다. 사용자는 이걸 "한도가 다르면 끊긴다"로 겪었다.

## 목표
1. **전송 시작 알림:** 전송이 시작되면 두 PC 모두 짧은 알림(트레이 풍선)을 띄운다.
   - 보내는 PC: "게임컴으로 파일을 보내기 시작했어요: 파일이름 (69.6GB)"
   - 받는 PC: "송출컴에서 파일을 받기 시작했어요: 파일이름 (69.6GB)"
2. **진행 상황:** 트레이 아이콘에 마우스를 올리면 진행 상황이 보인다. 설정 창에서도 같은 내용이 1초마다 바뀌며 보인다.
   - 예: `파일 받는 중 32% · 22.4/69.6GB · 113MB/s · 약 7분 남음`
3. **끝/실패 알림:**
   - 받는 PC: "다 받았어요. 붙여넣으세요(Ctrl+V)"
   - 보내는 PC: "다 보냈어요"
   - 실패하면 이유를 알린다.
4. **한도 서로 알려 주기:** 연결될 때와 한도를 바꿀 때 두 PC가 자기 한도를 상대에게 알려 준다.
   - 한도가 다르면 연결은 그대로 둔다. 설정 창 한도 칸 옆에 빨간 경고를 띄운다: "상대 PC 한도는 500MB예요. 작은 쪽(500MB)까지만 보낼 수 있어요."
   - 트레이 메뉴의 한도 줄에도 상대 PC 한도를 함께 보여 준다.
   - 보내는 쪽은 두 한도 중 작은 값으로 먼저 확인한다. 넘으면 보내지 않고 "상대 PC 한도(500MB)보다 커서 보내지 않았어요"라고 알린다.
5. **한도만 바꾸면 연결 유지:** 다음 항목이 그대로면 저장해도 다시 연결하지 않는다. 대신 바로 적용하고, 상대에게 새 한도를 알린다.
   - 역할, 송출컴 IP, 포트, 비밀번호, 가두기 키, 빠른 전환 키
   - 모니터 배치가 바뀐 경우에는 다시 연결하지 않고 배치만 다시 적용한다.

## 하지 않을 것
- 화면에 따로 뜨는 진행 창. 게임컴 화면은 캡처보드로 방송에 바로 나가고, 송출컴 화면도 방송된다.
- 남은 디스크 공간 확인. 별도 작업으로 남긴다.

## 방식 (제 판단)
- 새 메시지 `PeerSettings(FileLimitMB)`를 추가한다. 이전 버전과는 섞어 쓸 수 없으므로 두 PC를 함께 업데이트한다.
- 진행률 계산과 문구 만들기는 화면과 상관없는 코드(Core)에 두고 자동 테스트로 확인한다.
- 보내는 쪽의 진행률은 전송 대기열에 넣은 양으로 센다. 대기열은 최대 약 1MB라서 실제와 거의 같다.
- 트레이 아이콘 글자는 윈도우가 127자로 제한한다. 길면 자른다.
