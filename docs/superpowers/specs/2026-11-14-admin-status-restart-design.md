# 관리자 권한 상태 알림과 다시 켜기 (짧은 설계)

## 왜

업데이트한 뒤 exe를 그냥 더블클릭하면 Monitor Bridge가 관리자 권한 없이 켜집니다. 그러면 윈도우가 관리자 권한 창과의 입력을 막습니다.
- **게임컴:** 관리자 권한으로 도는 게임 화면에서 가두기·빠른 전환 키와 커서 이동이 전혀 동작하지 않습니다. Alt+Tab으로 게임에서 나와야만 동작합니다. 실제로 겪었고, 관리자 권한으로 켜서 해결되는 것을 확인했습니다.
- **송출컴:** 설치·제거 창이나 관리자로 켠 OBS를 조작할 수 없습니다.

다른 사용자도 똑같이 겪을 문제라서, 상태를 분명히 보여 주고 바로 고칠 수 있는 버튼을 둡니다.

## 목표

- 두 PC 모두, 관리자 권한 없이 켜지면:
  - 켤 때 작업 표시줄 알림을 한 번 띄운다. **알림을 누르면 관리자 권한으로 다시 켠다.**
  - 트레이 메뉴의 버전 줄 아래에 `권한: 관리자 아님 (일부 프로그램·게임에서 동작 안 함)` 줄과 **관리자 권한으로 다시 켜기** 메뉴를 보여 준다.
  - 설정 창의 자동 실행 줄 아래에 빨간 안내와 **[관리자 권한으로 다시 켜기]** 버튼을 보여 준다(지금은 송출컴에만 안내가 있음).
- 관리자 권한일 때는 위 줄·메뉴·안내가 모두 보이지 않는다.
- 다시 켜기: 윈도우 관리자 권한 확인 창 → "예"면 새로 켜지고 지금 것은 꺼진다. "아니오"면 지금 것이 그대로 돌고, "관리자 권한으로 다시 켜지 않았어요"라고 알린다.

## 하지 않는 것

- exe를 항상 관리자 권한으로 실행하게 만들기. 탐색기 우클릭 붙여넣기도 같은 exe를 잠깐 실행하므로, 붙여넣을 때마다 확인 창이 뜨게 된다.
- 켤 때 묻지 않고 바로 다시 켜기. 게임컴 화면은 방송에 나가므로, 저절로 뜨는 확인 창이 방송에 보인다.

## 정한 것

- **알림 문구**(PC마다 겪는 문제가 다르므로 다르게):
  - 게임컴: `관리자 권한 없이 실행 중이라, 관리자 권한으로 도는 게임·프로그램 화면에서는 단축키와 커서 이동이 동작하지 않아요. 이 알림을 누르면 관리자 권한으로 다시 켜요.`
  - 송출컴: `관리자 권한 없이 실행 중이라 설치·제거 창, 관리자로 켠 OBS 같은 프로그램은 조작할 수 없어요. 이 알림을 누르면 관리자 권한으로 다시 켜요.`
- **설정 창 안내**: 위 문구에서 "이 알림을 누르면…" 대신 `아래 버튼을 누르면 관리자 권한으로 다시 켜요. 매번 자동으로 관리자 권한으로 켜려면 위 자동 실행을 켜 두세요.`
- **다시 켜는 방식**: 같은 exe를 관리자 권한으로(`runas`) 새로 실행하면서 지금 프로세스 번호를 넘긴다. 새 프로세스는 그 프로세스가 끝날 때까지(최대 10초) 기다린 뒤 "한 번만 실행" 확인을 한다. 지금 프로세스는 새 프로세스가 시작되면 평소 종료와 같은 방식(커서 원래대로 등)으로 끝난다.
- 설정 창에서 버튼을 누르면 설정 창을 닫고(저장하지 않음) 다시 켠다.
- 기록 파일에 `restart elevated requested` / `declined`를 남긴다.

## 함께 바꾸는 것: 가두기 중에도 빠른 전환

지금은 가둔 동안 빠른 전환 키가 막혀 있습니다. 게임 중에 가둬 둔 상태에서도 키 하나로 송출컴에 바로 넘어갈 수 있어야 합니다.

- **게임컴에서 가둔 상태**: 가둔 동안에는 키보드·마우스 감시를 끄고 가두기 키만 윈도우 단축키로 등록해 둡니다. 여기에 **빠른 전환 키도 함께 등록**합니다.
  - 누르면 가두기를 잠시 풀고 송출컴으로 넘어갑니다.
  - **게임컴으로 돌아오면 자동으로 다시 가둡니다**(사용자 결정). 빠른 전환으로 돌아오든, 커서를 밀어서 돌아오든, 연결이 끊겨서 돌아오든 같습니다. 트레이 아이콘도 다시 주황색이 됩니다.
  - 송출컴에 있는 동안 가두기 키를 누르면 지금처럼 송출컴 가두기가 켜지고 꺼집니다. 게임컴으로 돌아올 때 다시 가두는 것과는 따로 동작합니다.
  - 빠른 전환 키를 단축키로 등록하지 못하면(다른 프로그램이 쓰는 중) 가두기는 그대로 켜고, "가둔 동안 빠른 전환 키를 쓸 수 없어요. 다른 프로그램이 같은 키를 쓰고 있을 수 있어요."라고 알립니다.
- **송출컴에서 가둔 상태**: 빠른 전환 키를 누르면 송출컴 가두기를 풀고 게임컴으로 넘어갑니다. 다시 송출컴으로 갈 때 송출컴 가두기는 되살리지 않습니다(제 판단: 송출컴 가두기는 잠깐 쓰는 용도라 되살리면 오히려 헷갈림).
- **창을 끄는 중**(마우스 버튼을 누른 채)에는 지금처럼 빠른 전환을 막습니다. 넘어가면 창이 떨어지기 때문입니다.
- 설명서의 "가둔 동안에는 빠른 전환 키도 막혀요"를 위 내용으로 바꿉니다.

## 만드는 사람에게 맡기는 것

- 다시 켜기 코드를 둘 자리와 이름(예: `AutoStart`에 `RestartElevated()`).
- 테스트: 기다리기 인자 읽기(`--wait-for <pid>`), 알림 문구 고르기(역할별). 확인 창·재시작 자체는 수동 확인.
- README 3개 언어와 PDF의 "자주 막히는 문제"에 게임컴 증상(게임 중 단축키 안 먹음)과 다시 켜기 버튼을 추가.
