# 파일 전송 속도 제한 (짧은 설계)

## 왜

파일 전송은 지금 속도 제한이 없어서 1기가 랜선을 거의 다 씁니다(실측 약 107MB/s). 송출컴의 방송 업로드도 같은 랜선과 공유기를 지나가므로, 방송 중에 큰 파일을 옮기면 라이브가 끊길 수 있다는 피드백이 들어왔습니다. 공개 저장소라서 설정을 건드리지 않는 사용자가 많으니, 처음부터 안전한 값이 걸려 있어야 합니다.

## 목표

- 보내는 쪽의 파일 전송 최대 속도를 설정에서 숫자로 정한다. 단위는 MB/s.
- **기본값은 30MB/s.** 0을 넣으면 제한 없음. 최대값은 1,000.
- 설정 창에 접힌 설명 **"속도 기준 보기"**를 두고, 누르면 속도 기준표가 펼쳐진다.
- 사용설명서(README 3개 언어, PDF)에도 같은 기준표를 넣는다.

## 하지 않는 것

- 단계 고르기 목록. 사용자가 숫자 직접 입력을 골랐다.
- 방송 중인지 알아내서 자동으로 줄이기(OBS 연결 필요).
- 키보드·마우스 신호의 속도 제한. 지금처럼 파일보다 먼저 보낸다.

## 정한 것

- **적용 값**: 두 PC 값 중 작은 쪽. 단, 0(제한 없음)은 "가장 큰 값"으로 취급한다. 상대 값을 아직 모르면 내 값만 쓴다. 파일 복사 한도와 같은 방식이고, 어느 쪽이 보내든 송출컴의 설정이 지켜진다.
- **값 교환**: 새 메시지 종류 22 `PeerSpeed(int MBps)`. 연결 때 `PeerSettings` 바로 뒤에 보낸다. 예전 버전은 모르는 메시지를 조용히 버리므로 연결이 끊기지 않는다(그때는 내 값만 적용).
- **값을 바꾸면 바로 적용**: 전송 중에 저장해도, 상대가 값을 바꿔도 다음 조각부터 새 속도가 적용된다. 연결은 끊기지 않는다(지금 한도 저장과 같은 가벼운 저장).
- **속도 맞추기**: 보내는 쪽이 조각(60KB)을 보낼 때마다, 보낸 양에 비해 너무 빨리 왔으면 그만큼 기다린다. 받는 쪽은 바꾸지 않는다. 진행률과 남은 시간은 지금처럼 실제 속도로 계산되므로 따로 손대지 않는다.
- **설정 창**: "파일 복사 한도" 아래에 한 줄을 둔다. `파일 전송 속도 [ 30 ] MB/s  (0 = 제한 없음)`. 그 아래에 "속도 기준 보기 ▸" 링크를 두고, 누르면 기준표가 펼쳐진다("속도 기준 접기 ▾"). 두 PC 값이 다르면 한도 경고와 같은 빨간 글씨로 "상대 PC는 10MB/s예요. 작은 쪽(10MB/s)으로 보내요."라고 띄운다.
- **트레이 메뉴**: 지금의 한도 줄 아래에 속도 줄을 추가한다. 예: `전송 속도: 30MB/s (상대 PC 10MB/s → 10MB/s)`.

## 속도 기준표 (설정 창 접힌 설명과 매뉴얼에 같은 내용)

- 1MB/s는 인터넷 속도로 8Mbps예요.
- 1기가(1000Mbps) 환경: 최대 약 110MB/s. 공유기, 랜선, 두 PC의 랜카드가 모두 1기가를 지원해야 해요.
- 100메가(100Mbps) 환경: 최대 약 11MB/s. 위 셋 중 하나라도 100메가면 전체가 100메가로 동작해요(오래된 공유기, 랜선, 랜카드).
- 와이파이: 속도가 들쭉날쭉해요
- 방송 업로드는 보통 1~2MB/s 정도예요. 랜선에 자리가 남아 있어야 방송이 끊기지 않아요.

| 상황 | 추천 값 |
| --- | --- |
| 1기가(1000Mbps)를 지원하는 네트워크 환경에서 방송 중 (공유기, 랜선, 두 PC의 랜카드가 모두 1기가를 지원해야 함) | 30MB/s (기본값) |
| 100메가 환경(이 중 하나라도 100메가), 와이파이, 잘 모를 때 | 5~10MB/s |
| 방송하지 않을 때 | 0 (제한 없음) |

예상 시간표는 넣지 않는다. 전송 중에 진행 창과 트레이에서 남은 시간을 보여 주기 때문이다.

## 만드는 사람에게 맡기는 것

- 속도 맞추기 계산의 세부 방식(전송 시작부터의 누적 기준, 짧은 버스트 허용 정도).
- 설정 창 접힌 설명을 펼칠 때 창 크기가 늘어나는 방식. 단, 앞에서 정리한 줄 맞춤(명시적 칸 배치)은 깨지면 안 된다.
- 테스트: 속도 맞추기 계산, 두 값 중 적용 값 고르기(0 포함), `PeerSpeed` 인코딩, 설정 저장·불러오기(예전 config.json에 값이 없으면 30).
