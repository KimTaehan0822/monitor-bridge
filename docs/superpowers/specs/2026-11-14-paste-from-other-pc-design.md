# 우클릭으로 상대 PC 파일 붙여넣기 (설계)

> 이 설계는 `2026-11-13-receive-folder-design.md`(받은 파일 저장 폴더)를 대체한다.

## 왜
- 지금은 파일을 **복사(Ctrl+C)하는 순간** 상대 PC로 보낸다. 같은 PC 안에서 복사만 해도 상대 PC 다운로드 폴더가 채워진다. 사람들이 기대하는 동작이 아니다.
- Ctrl+V를 가로채면, 이 붙여넣기가 이 PC 안의 복사인지 상대 PC의 복사인지 프로그램이 짐작해야 한다. 짐작이 틀리면 엉뚱한 파일이 넘어가거나 평소 붙여넣기가 막힌다.
- 진행 상황이 트레이 글자에만 나와서 잘 보이지 않는다. 전송을 취소할 방법도 없다.

## 목표
1. **복사는 알리기만 한다.**
   - 파일을 복사하면 상대 PC에는 "이런 파일을 복사해 뒀다"는 목록(이름, 개수, 전체 크기)만 보낸다. 파일 내용은 보내지 않는다.
   - 그 PC에서 다른 것(글자, 이미지 등)을 복사하면 목록을 거둔다.
   - Ctrl+V는 건드리지 않는다. 윈도우가 지금처럼 그 PC의 클립보드를 붙여넣는다.
2. **우클릭 메뉴로 가져온다.**
   - 메뉴는 세 곳에 넣는다: 탐색기 폴더 빈 곳, 폴더 아이콘, 바탕화면.
   - 메뉴 이름: **"Monitor Bridge: 상대 PC에서 복사한 파일 여기에 붙여넣기"**
   - 윈도우 11에서는 **"더 많은 옵션 표시"** 안이나 **Shift+우클릭** 메뉴에 나온다(사용자 결정).
   - 메뉴를 누르면 확인 창이 뜬다: "송출컴에서 복사한 파일 {이름 외 N개}({크기})를 이 폴더로 가져올까요? {폴더}" [가져오기] [취소]
   - 가져올 파일이 없으면 "상대 PC에서 복사한 파일이 없어요. 상대 PC에서 파일을 먼저 복사(Ctrl+C)해 주세요."라고 알린다.
   - 확인 창은 커서 근처에 작게 띄운다.
3. **받는 위치:** 우클릭한 그 폴더다.
   - 받는 동안에는 그 폴더 안의 숨김 폴더에 먼저 쓴다. 다 받으면 그 자리로 옮긴다.
   - 이름이 겹치면 `이름 (2)`로 저장한다. 덮어쓰거나 합치지 않는다.
4. **진행 창**
   - 트레이 아이콘을 클릭하거나 전송 시작 알림을 누르면 작은 진행 창이 열린다.
   - 진행 창에는 파일 이름, 진행 막대, "32% · 22.4/69.6GB · 113MB/s · 약 7분 남음", [전송 취소] 버튼이 있다.
   - 저절로 뜨지 않는다. 방송 화면에 갑자기 나오지 않게 하기 위해서다.
   - 시작 알림(트레이 풍선)과 끝 알림은 지금처럼 띄운다. 끝 알림을 누르면 받은 폴더가 열린다.
5. **전송 취소**
   - 진행 창의 버튼, 두 PC 트레이 메뉴의 "파일 전송 취소" 중 어느 쪽에서든 취소할 수 있다. 어느 PC에서 눌러도 양쪽이 함께 멈춘다.
   - 취소되거나 실패하면 **받는 쪽의 반쯤 받은 파일(숨김 폴더 안)만** 자동으로 지운다.
   - **보내는 쪽 원본은 절대 지우거나 옮기거나 바꾸지 않는다.** 읽기 전용으로만 연다. 자동 테스트로 확인한다.
6. **설정 창과 안내서**에 사용법을 적는다. 우클릭 → (윈도우 11) 더 많은 옵션 표시 → 메뉴 이름 순서다.
7. **가두기 키와 빠른 전환 키를 비워 둘 수 있다.**
   - 설정 창의 각 키 칸 옆에 [지우기] 버튼을 둔다. 칸이 선택된 상태에서 Backspace나 Delete를 눌러도 지워진다.
   - 빈 칸에는 회색으로 "사용 안 함"이 보인다.
   - 비워 둔 키는 아예 쓰지 않는다. 그 키를 가로채지 않아서 다른 프로그램이 그대로 쓸 수 있다.
   - 두 키가 같으면 안 된다는 확인은 둘 다 정해졌을 때만 한다. 둘 다 비어 있는 것은 괜찮다.
   - 빈 값은 설정 파일에 `""`로 저장한다. 다시 켜도 기본값으로 돌아가지 않는다.
   - 안내서의 단축키 표에 "비워 두면 사용하지 않아요"를 적는다.

## 없애는 것
- 복사 즉시 자동 전송
- "받은 파일 저장 폴더" 설정과 설정 창의 해당 줄. 이미 저장된 값은 무시한다.
- 숨김 폴더 대신 쓰던 예전 임시 폴더(`%TEMP%\MonitorBridge`). 정리 코드는 남겨서 예전 버전이 남긴 것을 지운다.

## 그대로 두는 것
- 글자와 이미지 클립보드 공유(복사하면 바로 넘어감)
- 파일 복사 한도와 두 PC 한도 비교·경고
- 옮기기에 실패하면 파일을 지우지 않고 보관하는 동작

## 방식 (제 판단)
- **메뉴 등록:** 프로그램이 켜질 때마다 HKCU 레지스트리(`Software\Classes\Directory\Background\shell`, `Directory\shell`, `DesktopBackground\shell`)에 등록한다. 관리자 권한은 필요 없다. exe 위치가 바뀌어도 다시 켜면 맞춰진다. 명령은 `"MonitorBridge.exe" --paste "%V"`다.
- **메뉴에서 실행된 프로그램 → 이미 켜진 프로그램:** 이름 있는 파이프로 폴더 경로를 넘기고 바로 끝난다.
  - 송출컴 프로그램은 관리자 권한으로 돌고, 메뉴로 실행된 쪽은 일반 권한이다. 그래서 파이프에 현재 사용자 접근을 명시적으로 허용한다.
  - 켜진 프로그램이 없으면 "Monitor Bridge가 실행 중이 아니에요"라고 알린다.
- **메시지:**
  - `FileListOffer(Count, TotalBytes, FirstName)`: 복사했다는 알림. 빈 목록이면 목록을 거둔다는 뜻이다.
  - `FileRequest(Id)`: "보내 주세요" 요청
  - 이후 전송은 기존 `FileOfferStart/Entry/Chunk/End/Cancel`을 쓴다.
  - 받는 쪽에서 취소할 때도 `FileCancel`을 보낸다.
- **보낼 파일 목록은 요청 시점에 다시 확인한다.** 복사한 뒤 원본이 지워졌거나 바뀌었으면 받는 쪽에 실패를 알린다.
- 두 PC를 같은 버전으로 함께 업데이트한다.

## 하지 않을 것
- 윈도우 11 새 우클릭 메뉴(패키지와 서명 필요)
- 화면 너머로 끌어다 놓기
- 남은 디스크 공간 확인
