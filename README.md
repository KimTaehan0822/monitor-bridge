# Monitor Bridge

게임컴 키보드·마우스 하나로 송출컴까지 조작하는 프로그램입니다. 인풋디렉터와 비슷하지만 **모니터 단위로 자유롭게 배치**할 수 있어요.

예를 들어 책상 위에 `송출컴 1 | 게임컴 | 송출컴 2` 순서로 모니터가 있으면, 커서도 그 순서대로 넘어갑니다. 한 PC에 모니터 세 대를 연결한 것처럼 쓸 수 있어요.

- 마우스·키보드 전달 (게임컴 → 송출컴)
- 클립보드 공유 (양방향): 글자, 이미지, 파일
- 가두기 키: 커서가 지금 있는 PC를 벗어나지 않게 막기 (게임할 때)
- 빠른 전환 키: 키 하나로 다른 PC로 바로 이동
- 게임컴과 연결된 상태에서 커서가 게임컴에 있는 동안 송출컴 커서는 숨김 (방송 화면에 화살표가 남지 않아요). 연결되기 전이나 연결이 끊기면 송출컴 커서는 그대로 보여요.

## 처음 설정하기

### 1. 송출컴에 키보드와 마우스를 잠깐 꽂으세요

> **처음 설정은 송출컴에서 직접 해야 합니다.** 이 프로그램이 실행되고 연결되기 전까지는 게임컴으로 송출컴을 조작할 수 없어요. 설정이 끝나면 다시 빼도 됩니다.

### 2. 인풋디렉터 같은 프로그램을 끄세요

인풋디렉터, Mouse Without Borders, Barrier 같은 프로그램과 **동시에 실행하면 입력이 꼬입니다.** 두 PC 모두에서 끄거나 지워 주세요.

### 3. 두 PC에서 `MonitorBridge.exe`를 실행하세요

처음 실행하면 설정 창이 뜹니다. 설치 과정은 없어요. exe 파일을 원하는 폴더에 두고 실행하면 됩니다.

**송출컴에서:**
1. "이 PC는"에서 **송출컴**을 고르세요.
2. **비밀번호**를 정해서 넣으세요. 게임컴에도 똑같이 넣어야 해요.
3. 창 아래쪽에 나오는 **이 PC의 IP**를 적어 두세요. (예: `192.168.0.10`)
4. **"윈도우 로그인 시 관리자 권한으로 자동 실행"**을 켜고 저장하세요. 관리자 권한 확인 창이 뜨면 "예"를 누르세요.

**게임컴에서:**
1. "이 PC는"에서 **게임컴**을 고르세요.
2. **송출컴 IP**에 송출컴에서 적어 둔 IP를 넣으세요.
3. **비밀번호**를 송출컴과 똑같이 넣으세요.
4. 저장하면 송출컴에 연결됩니다. 작업 표시줄 오른쪽 아이콘이 **청록색**이 되면 연결된 거예요.

### 4. 모니터를 책상 위 배치대로 놓으세요

게임컴 트레이 아이콘을 더블클릭하면 설정 창이 열립니다. 아래쪽 **모니터 배치**에서 모니터 사각형을 실제 책상 위 순서대로 끌어다 놓고 저장하세요.

- 청록색은 게임컴 모니터, 남색은 송출컴 모니터예요.
- 가까이 끌면 옆 모니터에 딱 붙습니다.
- 빨간 테두리가 보이면 모니터가 겹친 거예요. 옆으로 옮겨 주세요.

### 5. 확인한 뒤 송출컴 키보드와 마우스를 빼세요

게임컴 마우스로 송출컴 화면까지 오가는지 확인했으면, 송출컴 키보드와 마우스는 빼도 됩니다.

## 기본 단축키

| 기능 | 기본 키 | 설명 |
|---|---|---|
| 가두기 | `Scroll Lock` | 커서를 지금 있는 PC에 가둡니다. 다시 누르면 풀려요. 가둔 동안에는 트레이 아이콘이 주황색이고, 빠른 전환 키도 막혀요. |
| 빠른 전환 | `Ctrl + Alt + `` ` `` | 다른 PC로 바로 넘어갑니다. 그 PC에서 마지막에 있던 자리로 가고, 도착한 자리에 동그란 물결이 잠깐 퍼져서 커서를 찾기 쉬워요. 송출컴에 생긴 물결은 방송 화면에도 잠깐 보여요. |

설정 창에서 입력란을 클릭한 뒤 원하는 키를 누르면 바꿀 수 있어요.

- 게임컴에서 가두면 이 프로그램이 키보드·마우스 감시를 아예 멈춰서 게임에 영향을 주지 않아요.
- 송출컴에서 가두면 커서가 송출컴 모니터 밖으로 나가지 않아요. 가둔 동안에는 **송출컴 윈도우의 디스플레이 배치**를 따라 움직여서, 책상 위에서 송출컴 모니터 사이에 게임컴 모니터가 있어도 송출컴 모니터끼리는 오갈 수 있어요.
- 송출컴과 연결되지 않았을 때는 단축키를 포함한 모든 키와 마우스를 건드리지 않아요. 다른 프로그램이 같은 키를 써도 그대로 동작해요.

## 자주 막히는 문제

**연결이 안 돼요 (트레이 아이콘이 회색이에요)**
- 송출컴에서 프로그램이 실행 중인지 확인하세요.
- **윈도우 방화벽**: 처음 실행할 때 "액세스 허용" 창이 뜨면 **개인 네트워크**에 체크하고 허용하세요. 창을 놓쳤다면 송출컴의 "Windows Defender 방화벽 → 앱 허용"에서 MonitorBridge를 허용하거나, TCP 포트 24850을 열어 주세요.
- 송출컴 IP가 바뀌었을 수 있어요. 공유기 설정에서 송출컴 IP를 고정해 두면 편해요.
- "비밀번호가 달라서 연결하지 못했어요" 알림이 뜨면 두 PC의 비밀번호를 다시 똑같이 넣으세요.

**송출컴에 로그인 비밀번호가 걸려 있어요**
- 이 프로그램은 **로그인 화면을 조작할 수 없어요.** 프로그램이 로그인한 뒤에 실행되기 때문이에요.
- 송출컴에서 자동 로그인을 켜거나, 로그인할 때만 키보드를 꽂아 주세요.
- 로그인이 늦어져도 괜찮아요. 게임컴이 계속 연결을 시도하다가 송출컴 프로그램이 뜨면 알아서 붙습니다.

**OBS 같은 일부 프로그램이 클릭되지 않아요**
- 그 프로그램을 관리자 권한으로 실행했다면, 송출컴의 Monitor Bridge도 관리자 권한으로 실행해야 해요. 설정에서 **"관리자 권한으로 자동 실행"**을 켜고 송출컴을 다시 시작하세요.

**파일 복사가 안 돼요**
- 기본 한도는 500MB예요. 넘으면 알림만 뜨고 보내지 않아요. 설정의 **파일 복사 한도**에서 늘릴 수 있어요.
- **두 PC의 한도 중 작은 쪽까지만** 보낼 수 있어요. 한도가 서로 다르면 설정 창 한도 칸 아래에 빨간 경고가 뜨고, 트레이 메뉴에도 두 PC의 한도가 함께 보여요. 한도만 바꿔 저장하면 연결은 끊기지 않아요.
- 파일은 복사(Ctrl+C)하는 순간 상대 PC로 바로 전송돼요. 시작하면 두 PC에 알림이 떠요.
- 받은 파일은 받는 PC의 **받은 파일 저장 폴더**(기본: 다운로드 폴더)에 저장돼요. 설정 창에서 경로를 확인하고 `찾아보기…`로 바꿀 수 있어요.
- 다 받으면 "다 받았어요: 파일이름 → 폴더" 알림이 떠요. **알림을 누르면** 그 폴더가 열리고 받은 파일이 선택돼요. 클립보드에도 들어가서 Ctrl+V로 다른 곳에 붙여넣을 수도 있어요.
- 같은 이름의 파일이나 폴더가 이미 있으면 덮어쓰지 않고 `이름 (2)`처럼 저장해요.
- 전송 중에는 **트레이 아이콘에 마우스를 올리거나 설정 창을 열면** 진행률, 속도, 남은 시간이 보여요. 화면에 따로 창은 띄우지 않아요(방송 화면에 나오지 않게).
- 전송 중에 다른 파일을 복사하면 앞 전송은 취소돼요. 연결이 끊기면 전송이 멈추고 알림이 뜨니, 다시 복사해 주세요.
- 받는 동안에는 저장 폴더 안의 숨김 폴더(`.MonitorBridge-받는중`)에 쓰고, 다 받으면 저장 폴더로 옮겨요. 큰 파일은 저장 폴더가 있는 드라이브에 그만큼 빈 공간이 있어야 해요.

**송출컴 커서가 계속 안 보여요**
- 게임컴과 연결되어 있으면 정상이에요. 게임컴 커서가 송출컴 모니터로 넘어오면 다시 보여요.
- 게임컴과 연결되지 않았을 때는 숨기지 않아요. 연결이 끊기면 바로 다시 보여요.
- 프로그램이 이상하게 꺼져서 커서가 사라진 채 남았다면, Monitor Bridge를 다시 실행하세요. 시작할 때 커서를 원래대로 되돌려요.
- 게임컴에서도 같아요. 커서가 송출컴에 가 있을 때 프로그램이 강제로 꺼지면 게임컴 커서가 안 보일 수 있어요. 다시 실행하거나 로그아웃했다가 들어오면 돌아옵니다.

**Ctrl+Alt+Del이나 잠금 화면 뒤에 키가 눌린 것처럼 동작해요**
- 잠금 화면(Win+L)에서 돌아오면 자동으로 정리돼요.
- Ctrl+Alt+Del 화면에서는 키를 뗀 신호를 이 프로그램이 볼 수 없어요. 이상하면 Ctrl과 Alt를 한 번씩 눌렀다 떼세요.

## 지원하지 않는 것

- UAC(관리자 권한 확인) 창, Ctrl+Alt+Del 화면, 로그인 화면 조작
- 송출컴으로 넘어간 상태에서 게임하기 (게임은 게임컴에서 하고 가두기 키를 켜 두세요)
- PC 3대 이상
- 같은 공유기(LAN) 밖에서 연결하기

## 새 버전으로 바꾸기

**두 PC를 꼭 같은 버전으로 바꾸세요.** 버전이 다르면 연결이 끊겼다 붙기를 반복할 수 있어요.

> **예전 버전에서 받은 파일은 임시 폴더(`%TEMP%\MonitorBridge`)에 있어요.** 새 버전은 처음 켤 때 그 폴더를 비우니, 바꾸기 전에 필요한 파일을 옮겨 두세요.

1. 두 PC 모두 트레이에서 Monitor Bridge를 **종료**하세요.
2. 두 PC의 `MonitorBridge.exe`를 새 파일로 덮어쓰세요. 원래 있던 자리에 덮어써야 방화벽 허용과 자동 실행이 그대로 유지돼요.
3. 송출컴, 게임컴 순서로 다시 실행하세요.

## 기록 파일

문제가 생기면 `%AppData%\MonitorBridge\log.txt`를 확인하세요. 설정은 같은 폴더의 `config.json`에 저장돼요.
