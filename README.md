# Monitor Bridge

**한국어** | [English](README.en.md) | [日本語](README.ja.md)

게임컴 키보드·마우스 하나로 송출컴까지 조작하는 Windows 프로그램입니다. 인풋디렉터와 비슷하지만 **모니터 단위로 자유롭게 배치**할 수 있습니다.

예) 책상 위에 `송출컴 1 | 게임컴 | 송출컴 2` 순서로 모니터가 있으면, 커서도 그 순서대로 넘어갑니다. 한 PC에 모니터 세 대를 연결한 것처럼 쓸 수 있습니다.

- 마우스·키보드 전달 (게임컴 → 송출컴)
- 클립보드 공유 (양방향): 글자, 이미지, 파일
- 가두기 키: 커서가 지금 있는 PC를 벗어나지 않게 막기 (게임할 때)
- 빠른 전환 키: 키 하나로 다른 PC로 바로 이동. 도착한 자리에 물결이 퍼져 커서를 찾기 쉬움
- 게임컴과 연결된 동안 커서가 게임컴에 있으면 송출컴 커서는 숨김 (방송 화면에 화살표가 남지 않음). 송출컴 마우스를 움직이면 바로 다시 보이고, 설정에서 숨기기를 끌 수도 있음

## 필요한 것

- Windows 10 이상 64비트 PC 두 대 (게임컴 1대, 송출컴 1대)
- 두 PC가 같은 공유기(LAN)에 연결되어 있을 것
- 처음 설정할 때만 송출컴에 꽂을 키보드와 마우스

.NET을 따로 설치할 필요는 없습니다(exe 안에 들어 있습니다).

## 빠른 시작

### 1. 송출컴에 키보드와 마우스를 잠깐 꽂기

처음 설정은 송출컴에서 직접 해야 합니다. 이 프로그램이 실행되고 연결되기 전까지는 게임컴으로 송출컴을 조작할 수 없습니다. 설정이 끝나면 다시 빼도 됩니다.

### 2. 인풋디렉터 같은 프로그램 끄기

인풋디렉터, Mouse Without Borders, Barrier 같은 프로그램과 **동시에 실행하면 입력이 꼬입니다.** 두 PC 모두에서 끄거나 지워 주세요.

### 3. 두 PC에서 `MonitorBridge.exe` 실행하기

exe 파일을 원하는 폴더에 두고 실행합니다. 처음 실행하면 설정 창이 뜹니다.

**송출컴에서:**
1. **이 PC는**에서 **송출컴**을 고릅니다.
2. **비밀번호**를 정해서 넣습니다. 게임컴에도 똑같이 넣어야 합니다.
3. 창 아래쪽에 나오는 **이 PC의 IP**를 적어 둡니다. (예: `192.168.0.10`)
4. **윈도우 로그인 시 관리자 권한으로 자동 실행**을 켜고 저장합니다. 관리자 권한 확인 창이 뜨면 **예**를 누릅니다.
5. 방화벽의 **액세스 허용** 창이 뜨면 **개인 네트워크**에 체크하고 허용합니다.

**게임컴에서:**
1. **이 PC는**에서 **게임컴**을 고릅니다.
2. **송출컴 IP**에 송출컴에서 적어 둔 IP를 넣습니다.
3. **비밀번호**를 송출컴과 똑같이 넣습니다.
4. 저장하면 송출컴에 연결됩니다. 작업 표시줄 오른쪽 아이콘이 **청록색**이 되면 연결된 것입니다.

### 4. 모니터를 책상 위 배치대로 놓기

게임컴 트레이 아이콘을 더블클릭하면 설정 창이 열립니다. 아래쪽 **모니터 배치**에서 모니터 사각형을 실제 책상 위 순서대로 끌어다 놓고 저장합니다.

- 청록색은 게임컴 모니터, 남색은 송출컴 모니터입니다.
- 가까이 끌면 옆 모니터에 딱 붙습니다.
- 빨간 테두리가 보이면 모니터가 겹친 것입니다. 옆으로 옮겨 주세요.

### 5. 확인한 뒤 송출컴 키보드와 마우스 빼기

게임컴 마우스로 송출컴 화면까지 오가는지 확인했으면, 송출컴 키보드와 마우스는 빼도 됩니다.

## 단축키

| 기능 | 기본 키 | 설명 |
| --- | --- | --- |
| 가두기 | `Scroll Lock` | 커서를 지금 있는 PC에 가둡니다. 다시 누르면 풀립니다. 가둔 동안에는 트레이 아이콘이 주황색입니다. 가둔 동안에도 빠른 전환 키로 다른 PC로 넘어갈 수 있고, 게임컴에서 가둔 채 넘어가면 송출컴에서도 가둔 상태라 빠른 전환 키로만 돌아오고, 돌아오면 다시 가둡니다. 송출컴에서 가두기 키를 누르면 가두기가 완전히 풀립니다 |
| 빠른 전환 | ``Ctrl + Alt + ` `` | 다른 PC로 바로 넘어갑니다. 그 PC에서 마지막에 있던 자리로 가고, 도착한 자리에 물결이 잠깐 퍼집니다. 송출컴에 생긴 물결은 방송 화면에도 잠깐 보입니다 |

- **키 바꾸기**: 설정 창에서 입력란을 클릭하면 칸 색이 바뀌고 "새 키를 누르세요"가 나옵니다. 그동안은 지금 단축키가 실행되지 않으니 원하는 키를 누르면 됩니다(Esc: 취소).
- **안 쓰기**: 칸을 비우면(**[지우기]** 버튼, 또는 칸을 누르고 Backspace) 그 기능은 쓰지 않고, 그 키도 가로채지 않습니다.
- 게임컴에서 가두면 이 프로그램이 키보드·마우스 감시를 아예 멈춰서 게임에 영향을 주지 않습니다.
- 송출컴에서 가두면 커서가 송출컴 모니터 밖으로 나가지 않습니다. 이때는 **송출컴 윈도우의 디스플레이 배치**를 따라 움직여서, 책상 위에서 송출컴 모니터 사이에 게임컴 모니터가 있어도 송출컴 모니터끼리는 오갈 수 있습니다.
- 송출컴에서 창을 끄는 동안(마우스 버튼을 누른 채)에도 송출컴 윈도우의 디스플레이 배치를 따라 움직여서, 송출컴 모니터끼리 창을 끌어 바로 옮길 수 있습니다. 버튼을 떼면 원래 배치로 돌아옵니다.
- 송출컴과 연결되지 않았을 때는 단축키를 포함한 모든 키와 마우스를 건드리지 않습니다. 다른 프로그램이 같은 키를 써도 그대로 동작합니다.

## 파일 옮기기

1. 보낼 PC에서 파일이나 폴더를 복사(Ctrl+C)합니다. **복사만 해서는 아무것도 전송되지 않습니다.** 상대 PC에 "이런 파일을 복사해 뒀다"는 목록만 알려 줍니다.
2. 받을 PC의 탐색기에서 넣고 싶은 폴더(또는 바탕화면) 빈 곳을 **우클릭**합니다.
   - 윈도우 11은 **더 많은 옵션 표시**를 누르거나, 처음부터 **Shift+우클릭** 합니다.
3. **Monitor Bridge: 상대 PC에서 복사한 파일 여기에 붙여넣기**를 누릅니다.
4. 커서 옆에 "이 폴더로 가져올까요?" 창이 뜨면 **[가져오기]**를 누릅니다. 그때부터 전송됩니다.
5. 전송이 시작되면 알림이 뜹니다. **트레이 아이콘이나 알림을 누르면** 진행 창이 열립니다(진행률, 남은 시간, 전송 취소 버튼). 진행 창은 방송 화면에 나오지 않도록 저절로 뜨지 않습니다.
6. 다 받으면 "다 받았어요" 알림이 뜨고, 누르면 그 폴더가 열립니다.

- 평소의 Ctrl+V 붙여넣기는 이 프로그램이 건드리지 않습니다.
- 같은 이름이 이미 있으면 덮어쓰지 않고 `이름 (2)`처럼 저장합니다.
- **전송 취소**: 진행 창의 **[전송 취소]** 또는 트레이 메뉴의 **파일 전송 취소**를 누릅니다. 어느 PC에서 눌러도 양쪽이 함께 멈춥니다. 반쯤 받은 파일은 자동으로 지우고, **보내는 쪽의 원본 파일은 절대 지우거나 바꾸지 않습니다.**
- **복사 한도**: 기본 500MB, 최대 100,000MB입니다. **두 PC의 한도 중 작은 쪽까지만** 보낼 수 있습니다. 한도가 서로 다르면 설정 창에 빨간 경고가 뜨고, 트레이 메뉴에 두 PC의 한도가 함께 보입니다.
- **전송 속도**: 기본 **30MB/s**까지만 보냅니다. 파일이 랜선을 꽉 채우면 송출컴의 방송 업로드가 밀려서 방송이 끊길 수 있기 때문입니다. 설정 창의 **파일 전송 속도**에서 바꿀 수 있고(최대 1,000MB/s), **0을 넣으면 제한 없이** 보냅니다. **두 PC 중 작은 값**으로 보내며(0은 제한 없음이라 가장 큰 값으로 칩니다), 전송 중에 바꿔 저장해도 바로 적용됩니다.

### 속도 기준

<details><summary>펼쳐 보기</summary>

- 1MB/s는 인터넷 속도로 8Mbps입니다.
- 1기가(1000Mbps) 환경: 최대 약 110MB/s. 공유기, 랜선, 두 PC의 랜카드가 모두 1기가를 지원해야 합니다.
- 100메가(100Mbps) 환경: 최대 약 11MB/s. 셋 중 하나라도 100메가면 전체가 100메가로 동작합니다.
- 와이파이는 속도가 들쭉날쭉합니다.
- 방송 업로드: FHD 비트레이트 8000kbps 기준 1시간에 약 4GB(여유 있게 잡은 값)로, 속도로는 약 1.1MB/s입니다. 랜선에 자리가 남아 있어야 방송이 끊기지 않습니다.

| 상황 | 추천 값 |
| --- | --- |
| 1기가(1000Mbps)를 지원하는 네트워크 환경에서 방송 중 (공유기, 랜선, 두 PC의 랜카드가 모두 1기가를 지원해야 함) | 30MB/s (기본값) |
| 100메가 환경(이 중 하나라도 100메가), 와이파이, 잘 모를 때 | 5~10MB/s |
| 방송하지 않을 때 | 0 (제한 없음) |

## 설정

| 항목 | 기본값 | 뜻 |
| --- | --- | --- |
| 이 PC는 | | 게임컴(키보드·마우스가 있는 PC) 또는 송출컴 |
| 송출컴 IP | | 게임컴에서만. 송출컴 설정 창에 나오는 IP |
| 비밀번호 | | 두 PC에 똑같이. 연결을 암호화하는 데 씁니다. 옆의 **보기**를 체크하면 글자가 보입니다 |
| 향상된 보안 모드 | 꺼짐 | 두 PC 모두 켜야 연결됩니다. 비밀번호를 암호화해서 저장하고, 8자 이상만 쓸 수 있습니다. 송출컴은 같은 곳에서 비밀번호가 5번 틀리면 3분 동안 연결을 막습니다 |
| 이 PC 커서 숨기기 | 켜짐 | 송출컴에서만. 끄면 송출컴 커서를 숨기지 않습니다. 켜 두어도 송출컴 마우스를 움직이면 바로 보입니다 |
| 가두기 키 / 빠른 전환 키 | `Scroll Lock` / ``Ctrl+Alt+` `` | 게임컴에서만. 비워 두면 그 기능은 쓰지 않음 |
| 파일 복사 한도 | 500MB | 최대 100,000MB. 두 PC 중 작은 쪽이 적용됨 |
| 파일 전송 속도 | 30MB/s | 최대 1,000. 0 = 제한 없음. 두 PC 중 작은 쪽이 적용됨. **속도 기준 보기**를 누르면 기준이 펼쳐짐 |
| 자동 실행 | | 윈도우 로그인 때 실행. 송출컴은 관리자 권한으로 |
| 모니터 배치 | | 게임컴에서만. 실제 책상 위 순서대로 |

연결에는 TCP 포트 `24850`을 씁니다.

## 트레이 아이콘

| 색 / 메뉴 | 뜻 |
| --- | --- |
| 청록색 | 연결됨 |
| 회색 | 연결 안 됨 |
| 주황색 + 자물쇠 표시 | 가두기 켜짐 |
| 메뉴 맨 위 `버전:` 줄 | 이 PC의 Monitor Bridge 버전 |
| 복사 한도 줄 | 두 PC의 파일 복사 한도 |
| 파일 전송 속도 줄 | 이 PC의 전송 속도. 두 PC가 다르면 양쪽 값과 실제로 쓰는 값 |
| 파일 전송 보기 / 파일 전송 취소 | 진행 창 열기 / 전송 멈추기 |
| 권한: 관리자 아님 줄 / 관리자 권한으로 다시 켜기 | 관리자 권한 없이 실행 중일 때만 보입니다. 누르면 관리자 권한 확인 창이 뜨고, "예"를 누르면 관리자 권한으로 다시 켜집니다 |

## 자주 막히는 문제

| 증상 | 원인 | 할 일 |
| --- | --- | --- |
| 연결이 안 됨 (아이콘 회색) | 송출컴 프로그램이 꺼짐, 방화벽, IP 바뀜 | 송출컴에서 실행 확인 → "Windows Defender 방화벽 → 앱 허용"에서 MonitorBridge 허용(또는 TCP 24850 열기) → 송출컴 IP 다시 확인(공유기에서 고정하면 편함) |
| "비밀번호가 달라서 연결하지 못했어요" | 두 PC 비밀번호가 다름 | 두 PC에 똑같이 다시 넣기 |
| "두 PC의 Monitor Bridge 버전이 달라요" | 한쪽만 업데이트함 | 키보드·마우스는 그대로 됩니다. 두 PC를 같은 버전으로 맞추기 |
| 송출컴 로그인 화면을 조작할 수 없음 | 프로그램은 로그인한 뒤에 실행됨 | 송출컴 자동 로그인을 켜거나, 로그인할 때만 키보드 꽂기 |
| 프로그램 설치·제거 창, OBS 같은 일부 프로그램이 조작되지 않음 | 그 프로그램은 관리자 권한인데 송출컴의 Monitor Bridge는 관리자 권한 없이 실행됨(exe를 더블클릭해서 켠 경우 등). 이때는 켤 때 알림이 뜨고 설정 창에 빨간 안내가 보입니다 | 송출컴 설정에서 **관리자 권한으로 자동 실행**을 켜고 PC를 다시 시작하거나, exe를 우클릭 → **관리자 권한으로 실행** |
| 게임 중에 가두기·빠른 전환 키와 커서 이동이 안 됨 (Alt+Tab으로 게임에서 나와야 됨) | 게임컴 Monitor Bridge가 관리자 권한 없이 실행됨. 켤 때 알림이 뜨고 트레이 메뉴와 설정 창에 표시됩니다 | 알림, 트레이 메뉴, 설정 창의 **관리자 권한으로 다시 켜기**를 누르기. 매번 자동으로 하려면 설정에서 자동 실행 켜기 |
| 우클릭 메뉴가 안 보임 | 윈도우 11 새 메뉴, 또는 한 번도 실행 안 함 | **더 많은 옵션 표시** 또는 Shift+우클릭, Monitor Bridge 한 번 실행 |
| "Monitor Bridge가 실행 중이 아니에요" | 그 PC에서 꺼져 있음 | 그 PC에서 먼저 켜기 |
| 파일 복사가 안 됨 | 한도 초과, 빈 공간 부족 | 두 PC 한도 확인. 받는 동안 받는 폴더 안의 숨김 폴더(`.MonitorBridge-받는중`)에 먼저 쓰므로 그만큼 빈 공간 필요 |
| 받은 파일을 폴더로 못 옮김 | 백신 등이 파일을 잡고 있음 | 파일은 지우지 않고 알림에 나온 숨김 폴더에 그대로 둡니다 |
| 송출컴 커서가 안 보임 | 게임컴과 연결되어 있으면 정상 | 송출컴 마우스를 움직이면 바로 보입니다. 게임컴 커서가 넘어와도 보입니다. 숨기기가 싫으면 설정에서 **이 PC 커서 숨기기**를 끄기 |
| "향상된 보안 모드를 켜 주세요" 알림 | 한쪽 PC만 향상된 보안 모드를 켬 | 두 PC 모두 켜거나 모두 끄기 |
| "비밀번호가 5번 틀려서 3분 동안 연결을 막았어요" | 향상된 보안 모드에서 비밀번호가 계속 틀림 | 두 PC 비밀번호를 맞춘 뒤 3분 기다리기 |
| "저장된 비밀번호를 이 PC에서 열 수 없어요" | 향상된 보안 모드로 저장한 설정 파일을 다른 PC나 다른 윈도우 계정으로 옮겨 옴 | 설정 창에서 비밀번호를 다시 넣기 |
| Ctrl+Alt+Del 뒤에 키가 눌린 것처럼 동작 | 그 화면에서는 키를 뗀 신호를 볼 수 없음 | Ctrl과 Alt를 한 번씩 눌렀다 떼기 |

문제가 생기면 `%AppData%\MonitorBridge\log.txt`를 확인하세요. 설정은 같은 폴더의 `config.json`에 저장됩니다.

## 지원하지 않는 것

- UAC(관리자 권한 확인) 창, Ctrl+Alt+Del 화면, 로그인 화면 조작
- 송출컴으로 넘어간 상태에서 게임하기 (게임은 게임컴에서 하고 가두기 키를 켜 두세요)
- PC 3대 이상
- 같은 공유기(LAN) 밖에서 연결하기

## 새 버전으로 바꾸기

1. 두 PC 모두 트레이에서 Monitor Bridge를 **종료**합니다.
2. 두 PC의 `MonitorBridge.exe`를 새 파일로 덮어씁니다. 원래 있던 자리에 덮어써야 방화벽 허용과 자동 실행이 그대로 유지됩니다.
3. 송출컴, 게임컴 순서로 다시 실행합니다.

버전이 달라도 키보드·마우스 연결은 끊기지 않지만, 새 기능 일부가 동작하지 않을 수 있으니 두 PC를 같은 버전으로 맞춰 주세요.
